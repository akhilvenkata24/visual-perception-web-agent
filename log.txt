  - **Context-Aware Privacy Decision Formula**: Evaluates `Sensitivity x Task Relevance x Necessity x Disclosure Risk` for every detected PII entity. Enforces minimum sufficient disclosure (`ALLOW`, `MASK`, `TOKENIZE`, `ABSTRACT`, `LOCAL_ONLY`, `BLOCK`).

    - Task `"Who's this person?"` $\to$ Name: `ALLOW`, Email: `MASK`, Phone: `MASK`, Photo: `LOCAL_ONLY`.

  - **Final Privacy Validation**: String-searches the serialized sanitized context before passing to verify zero prohibited raw values (`MASK`, `BLOCK`, `LOCAL_ONLY`) survived redaction.
  - **Non-Destructive Integrity**: Original DOM and `PageModel` are never mutated.
  - **Zero Network Requests**: 100% local in-browser execution.

## Phase 8: Local Action Firewall
- **Date**: 2026-09-09
- **Action**: Built local Action Firewall in `extension/src/agent/actionFirewall.ts`.
- **Key Capabilities**:
  - **Untrusted Input Guarantee**: Treats all AI-generated actions as untrusted input. Enforces `LOCAL STATE > GEMINI OUTPUT`.
  - **Validation Checklist**:
    1. **Schema Validation**: Rejects malformed or incomplete payload objects.
    2. **Action Allowlist**: Restricts permitted actions to `['click', 'type', 'scroll', 'navigate', 'select', 'none']`. Rejects unknown/prohibited commands (`execute_javascript`).
    3. **Element ID Verification**: Verifies `element_id` exists in local `PageModel`. Rejects hallucinated IDs (`profile_999`).
    4. **Stale Page State Protection**: Compares page URL and perception timestamp. Rejects stale actions generated for old page states.
    5. **Navigation Safety**: Rejects dangerous schemes (`javascript:`, `data:`, `file:`) for `navigate` actions.
    6. **Dangerous Action Interception**: Rejects or flags destructive operations (`delete`, `send`, `purchase`) as `REQUIRE_CONFIRMATION`.
  - **Separation of Concerns**: Action Firewall strictly performs validation (`ALLOW`, `DENY`, `REQUIRE_CONFIRMATION`). DOM execution is decoupled into Phase 9 (`actionExecutor.ts`).
